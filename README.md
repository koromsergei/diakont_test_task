# Тестовое задание: три приложения

## Подготовка виртуальных портов

Создайте пару виртуальных портов командой:

```bash
sh create_ports.sh
```

Пример результата:

```bash
2026/05/13 13:44:05 socat N PTY is /dev/pts/5
2026/05/13 13:44:05 socat N PTY is /dev/pts/6
```

После этого укажите созданные порты в файле `common/M/config.py`:

```python
M2_PORT = '/dev/pts/5'
M3_PORT = '/dev/pts/6'
```

> Важно: не закрывайте терминал, в котором запущен `create_ports.sh`, иначе виртуальные порты перестанут существовать.

## Запуск приложений

Запустите все три приложения командой:

```bash
sh run_all.sh
```
